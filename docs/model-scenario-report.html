The Edge Negotiator · full-scale phase · model × scenario analysis

Why the same on-device model wins one junction and loses another

A small language model that beats the standard MaxPressure controller by 25% on a congested London arterial makes traffic worse on a free-flowing grid. This report explains that gap with the methodology benchmark suites use to separate a model effect from a scenario effect — and shows, honestly, what our single-seed data can and cannot support.

The headline: scenario dominates (which junction you are on explains far more than which model), but there is a genuine model×scenario interaction on top of it — the model ranking reverses between the arterial and the grids.

02

The interaction: a rank reversal

In factorial analysis a disordinal interaction is exactly when the lines cross — the rank order of the models reverses across scenarios (Loftus, 1978). That is precisely what we see: qwen2.5-0.5b wins Euston and is beaten everywhere else; qwen3-0.6b wins on all three grids and only comes second on Euston. Nets are ordered left-to-right by how hard MaxPressure gridlocks.

qwen2.5-0.5b (corridor specialist) qwen3-0.6b (robust all-rounder) lines cross → disordinal interaction

Fig 1. The lines cross between the grids and Euston: qwen2.5-0.5b has the single best cell (Euston −25%) yet the worst grid collapse (+112%), while qwen3-0.6b is flatter and more robust. A crossing = the model ranking depends on the scenario. Descriptive, n=1/cell (Alin & Kurt, 2006): no significance is claimed on the interaction itself.

Why the two models differ on the same net. qwen3-0.6b is the newer-generation, slightly larger model; across every topology it is steadier (its worst cell is +41% vs qwen2.5's +112%). The smaller qwen2.5-0.5b is higher-variance — it finds the biggest single win but also the biggest blow-up. Model capacity buys robustness to the harder substrate, not a bigger peak.

03

The trap: Simpson's paradox

It is tempting to say "the win grows with congestion." Pooled across all four topologies the correlation between baseline gridlock and win size is +0.73 (Spearman +0.73) — positive. But that number is a sign-reversing Simpson's paradox (Yule–Simpson): within the two genuinely congested nets the correlation is −0.93. Bloomsbury has more gridlock than Euston (186 vs 107) yet a smaller win. The positive pooled number is manufactured by the two free-flowing grids sitting at the bottom-left.

free-flowing grid (0 teleports) qwen2.5-0.5b qwen3-0.6b

Fig 2. Pooled trend (grey dashed, +0.73) points up; the within-congested trend (red, −0.93) points down. Reporting only the pooled number would be the paradox. A Pearson r on four topology points is fragile, so we report Spearman and leave-one-out alongside it and treat the stratified (within-regime) correlation as primary (Croux & Dehon; Agarwal et al., 2021).

What this means for the thesis. The honest claim is a regime separation, not a graded law: the SLM helps in the congested regime and hurts in the free-flowing one. Where it helps, more gridlock does not mean a bigger win.

05

Why: substrate, then a real interaction

Decomposing the outcome variance across the model×topology matrix (descriptive η², two-way, n=1/cell) attributes it as:

scenario 80% interaction 13% model 7%

Fig 4. Which junction you are on explains ~6× more than which model. But the 13% interaction is the rank reversal — not noise, a real effect the matrix would hide if you averaged over scenarios. Residual folds into interaction at n=1 (no error d.f.).

The mechanism behind the losses. The SLM is event-gated: it only overrides MaxPressure above a queue threshold. On the free-flowing grids it fires far more often and its proposals are served far more often than on Euston — and that is exactly where it hurts. "Authored share" is the fraction of consultations whose SLM proposal was served (a policy-divergence proxy: how much the SLM steers away from the MaxPressure shield).

MaxPressure is throughput-optimal and near-ideal when traffic flows freely, so every extra myopic override is a chance to disrupt coordination it cannot see. Raising the gate to mute this (a swept congestion gate, 2→5→12) reduces but never removes the grid loss — and it also erodes the real wins, so it is a partial lever, not a fix (recorded as an honest negative).

06

How the literature does this — and how we replicated it

  • Interaction, not anomaly. A rank reversal across scenarios is a disordinal interaction; when it is disordinal the main effects are not interpretable alone and you report the per-scenario (simple) effects (Loftus, 1978). We lead with the slope chart (Fig 1) because a crossing makes the interaction unmistakable.
  • Variance attribution. Two-way decomposition into model / scenario / interaction with η² = SSeffect/SStotal (Montgomery). At one observation per cell the interaction is not inferentially testable (Alin & Kurt, 2006), so we report η² as descriptive and never attach a p-value.
  • Cross-model benchmarking. Per-scenario normalised cells + win rate, the HELM convention (Liang et al., 2022); normalised score in the BIG-bench NPM sense (Srivastava et al., 2022). A critical-difference diagram (Demsar, 2006) would need many more tasks than four, so we do not draw one — stated, not faked.
  • Simpson's paradox. Our +0.73 pooled / −0.93 within-congested sign flip is the textbook Yule–Simpson effect; the fix is to report the stratified correlation as primary, add a rank-based Spearman (robust to leverage; Croux & Dehon), and run leave-one-out because an r on four points is otherwise uninterpretable (Agarwal et al., 2021).
  • Mechanistic error analysis. Attributing a policy's win to a regime by bucketing outcomes by a covariate (here congestion) and reporting behavioural divergence from the baseline (agreement/override rate; our "authored share") — standard policy-distance practice (Schulman et al., 2015).
The pitfalls we actively guarded against: over-reading single seeds (kept everything descriptive), Simpson's paradox (stratified-first), leverage on a 4-point correlation (Spearman + leave-one-out), and cherry-picked thresholds (the congestion gate was swept, not tuned to a winning value).
07

What n=1 does and does not license

  • Licensed now (large within-run sample): the interaction plot, the normalised benchmark heatmaps, win rate, and every per-decision behavioural metric (consultations, authored share, congestion-bucketed trends).
  • Not licensed until ≥2 seeds/cell: any inferential interaction test, cross-seed confidence intervals, interquartile-mean performance profiles, and trustworthy 4-point correlations. These are flagged as exploratory throughout.
  • Coverage is uneven by design: the topology axis covers 2 models, the config axis covers 4 on Euston. It is not one balanced grid, and the report never treats it as one.
  • Powered significance stays gated on real time-resolved TfL hourly + turning data — missing data, not missing code.
