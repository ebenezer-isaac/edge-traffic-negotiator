Honest reading: the SLM is a congestion-regime specialist. It wins on the two real congested London nets (where MaxPressure gridlocks, teleports>0) and loses on the free-flowing synthetic grids (zero teleports, MaxPressure already near-optimal). Mean win +9.3% congested vs −62.7% free-flowing. It is not a monotonic "more gridlock = bigger win" law: within the congested nets the direction inverts (Bloomsbury has more gridlock than Euston yet a smaller win; rcongested = −0.93). grid4×4 (SLM +112% worse) falsifies any "always helps" claim — reported, not hidden. A follow-up congestion gate (fire the SLM only above a queue threshold) was tested and swept (gate 2/5/12): it is an honest negative — it reduces but never removes the grid regressions (grid4×4 still +76% at gate 12) while also shrinking some real wins, so it does not overturn the result. The safe deployment is per-(net, model) validation, not a per-tick gate.

H2 · Trust (the tamper-evident audit)

Accident reconstruction

8 / 8 checks

From the verified log alone: WHAT happened (phase sequence), HOW (signed inputs + policies), WHICH KEY drove it. A forged signature that still passes the hash-chain is caught by the per-sender identity check.

Multi-vehicle authorisation

P = R = 1.00

Ambulance/fire/police may preempt; maintenance never; a works key posing as an ambulance is flagged. Across 26 balanced adversarial cases: zero dangerous false grants.

Ledger + anchor mechanism

salted root · ≥2 witnesses

Ed25519-signed, hash-chained, Merkle-committed, salted for privacy. A planted "two different histories" (equivocation) attack is detected. Honestly labelled not externally anchored (no write to the public log).

Coupling blind spot

documented boundary

The attack controls the phase, which gates witness coverage — an insider can open a "coverage desert." Demonstrated as a modelled pilot; the severe statistical claim is honestly gated.

Crash → UK-law suite

7 / 7 scenarios

Each pre-defined crash (civilian/ambulance/maintenance/amber/conflicting-green/dark-signal/spoofed-EV): chain + signatures verify, an imposter re-sign is caught, and the governing UK rule (RTA 1988 s36, TSRGD 2016, Griffin, Bird v Pearce, HC 176) is inferred from the verified facts, not asserted.

Trust coefficient · local sensing = ultimate truth

honest 0.93 · liar 0.01 (locked out)

A claim is scored against the recipient's own local sensing (never doubted). Truth-telling raises trust (10 truths 0.5→0.90); a single lie collapses it −0.65. Wired live into EV corroboration as discount-only: a caught liar loses corroboration power, but trust never forces a preempt and never gates local sensing — the phantom-defence cannot regress.

09What is not claimed (read this to the supervisor)

  • Every traffic result is descriptive, n=1 per cell (one seed each; multi-seed uses 5). No statistical-significance claim is made until the powered runs.
  • The SLM is a congestion-regime specialist, not a universal MaxPressure-beater: it loses on free-flowing nets, and the multi-topology trend is a regime separation, not a monotonic law.
  • Demand is calibrated to daily-average government counts; the hourly profile is measured from one DfT survey day, and junction turning counts are still assumed. Bloomsbury/grid demand is a synthetic magnitude on a real/synthetic topology.
  • The powered (n≥30) inferential runs are deliberately gated until time-resolved TfL hourly + turning data lands — missing data, not missing code.
  • The newest qwen3.5 generation could not be benchmarked: this Foundry Local build cannot parse its model config (HTTP 500). Recorded as an infra gate, not a capability result.
  • The crash→law output is a cited evidence pack for a human adjudicator, not a binding legal verdict; authority fault is legally weak (misfeasance branch only).
  • The audit mechanism is credited to Certificate Transparency and the LLM-control idea to LLMLight; the contribution is combining them on real London nets with an honest feasibility + scale answer.
