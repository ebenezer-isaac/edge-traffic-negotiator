## 3. The SLM (mandatory): a self-contained second contribution

**Job A — citation-faithful legal-reasoning note (PRIMARY SLM metric).** Given the *cryptographically-verified AND quorum-complete* audit window + retrieved statute, the SLM writes the **internal, non-evidential, counsel-gated** note:
```
{ candidate_origin: attacker-key|system-classifier|system-detector|sensor-fed-spoof|colluding-keys|legitimate|unknown,
  cited_rules: ["RTA1988-s36", ...], reasoning: "<=120 words linking VERIFIED facts to cited rules",
  fault_weight_note: "MUST-rule (statute) | should-rule (advisory, RTA s.38(7))" }
```
**PRIMARY metric = citation-correctness + false-citation-rate (FCR) on NOVEL legal fact-combinations** (the one place genuine judgment lives; Dahl et al. 2024). Measured vs annotator-blind held-out applicable-rule labels; both faithfulness AND FCR on novel combos are gated on the SAME annotator-blind novel-combo gold, 2-rater Cohen's kappa ≥ 0.6 else NOT_ASSESSED; faithfulness graded against STATUTE TEXT by qualified humans (no LLM-as-judge). Baseline = a deterministic rule-to-text template with a graceful fallback ("nearest applicable rule; no exact match"). Pin, PRE-RUN under the seal: the numeric FCR ceiling (justified from legal-harm — a false criminal-statute citation is high-harm), the exact both-metrics dominance rule (tie-handling), AND the abstention-scoring rule (an abstaining template counts as correct-refusal where no rule applies, incorrect where one does — so abstention is a genuine competitor, not free). A distinction-grade result may be "honest template abstention beats confident SLM hallucination." A citation whose supporting fact lacks verified provenance is a validation FAILURE (anti prompt-injection §6.9).

**Origin classification is NOT the primary metric** (methods F1, consistency B1): the deterministic partition `f(record)` over two mechanical features (signing-key count 0/1/≥2 + recomputed-corroboration presence) decides exactly THREE classes {keyless-lone-sighting, uncorroborated-signed, corroborated}, so accuracy over them is ~100% by construction — a VERIFICATION CHECK, reported for completeness, not a measurement of reasoning. Distinguishing `colluding-keys` from honest corroboration inside the corroborated cell is the SAME provenance-indistinguishable veracity judgment as the triad (§8) and is NOT separately scored unless an independent measured-position predicate exists. `system-classifier`/`system-detector` trigger ONLY via a PURELY PROVENANCE-DERIVED predicate with zero `ground_truth` reference (e.g. "a corroboration check the detector logged as failed is contradicted by an independently-signed sighting record present in the verified window"); if no such predicate exists the class is pre-declared non-separable → `unknown`. D6's floor is TWO-SIDED (methods F1): FAIL if the separable fraction is below a floor (empty matrix) OR if per-cell accuracy is not statistically below 1.0 on cases engineered to require a non-trivial corroboration-validity judgment (stale / out-of-window / route-inconsistent sightings) — i.e. force a decision the deterministic partition cannot make, or drop "accuracy" as a claimed finding.

**Job B — disambiguation classifier**, characterised under §8. Win-or-a-powered-null.

**Job C — robustness/adaptivity tradeoff.** Frozen SLM vs a HARDENED continual-learner. Pin concretely (methods M2/M6): the continual model class + online update rule; a poisoning defense demonstrably applicable to THAT class (do NOT cite TRIM / Steinhardt-Koh-Liang — convex/regression defenses that do not compose with LLM fine-tuning; name a published LLM-continual/instruction-tuning sanitiser and justify applicability); the poison channel + budget as a fraction of the stream; a measurable attacker objective. Report robustness gain AND adaptivity loss, BOTH in the same external operational-harm currency (sec EV delay / FP%) with PRE-REGISTERED poisoning-vs-shift mixing weights (pinned to an external threat-likelihood estimate). Job C is REPORTED, NOT a claim-survival gate.

**The single load-bearing SLM job (methods M4/M5):** the headline SLM claim survives ONLY by winning **Job A** (citation-correctness dominating the template at the pre-registered MDE + FCR ceiling on novel combos). Job B and Job C are reported but NOT sufficient for survival. The kill-criterion is an AND on Job A, not an OR across arms. The two "primary" designations are reconciled: citation-correctness+FCR is the SOLE primary/load-bearing SLM metric; origin-classification is a verification check.

**The E2 rule + tie-break:** a validly-signed, uncorroborated claim that caused harm → `attacker-key` (wins the tie against catchable-phantom). Verdict inputs come ONLY from verified provenance; corroboration is RECOMPUTED from independently-signed sighting records (§6.6), never a self-asserted scalar. A frozen read-only worked-example fixture pins the expected verdict string.
